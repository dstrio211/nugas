# nugas.

Personal assignment tracker built with Vite and Supabase.

1. Create a Supabase project.
2. Run `supabase.sql` in Supabase SQL Editor.
3. Copy `.env.example` to `.env`, then fill the URL and anon key.
4. In Supabase Auth, enable Email provider and set the site URL to the final Vercel URL.
5. Run `npm install` then `npm run dev`.

For Vercel, add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` under Environment Variables before deploying.
